In the interview, I give some insight into how I got the game translated along with how general fan translations of this game are done.

About Lost Kefin

This game is a remake of Ys V on the SNES. This remake was published by Taito and developed by Access Co. just like how the other PS2 remakes of Ys 3 and 4 were done. This remake completely overhauls the gameplay, magic system, story, and overhauls the dungeons. One of the most major addition is Dogi is actually in the game.

About the translation

Link to GitHub page.
An overview for how the translation is done:

  • Extract the files from the game's DVD
  • Extract individual files from the "DATA.BIN" file
  • Decompile script files into custom "kscript" files
  • The kscript files contain useful info and context such as which character is speaking
  • Extract the strings from the kscript files onto spreadsheets
  • Translate the game into English on Google Sheets
  • During building, the text is pulled from Google Sheets, then inserted into the kscript files, then compiled back into the original format, then repacked into DATA.BIN, and rebuilt into a new ISO
  • Graphics files from DATA.BIN have a special format which I have documented
  • Graphics files are converted into PNG files for editing, which are then reinserted back into the given graphics file during building
  • Strings in the game's executable are exported into a spreadsheet, and then have their pointers updated during building
This translation was done thanks to the work of many volunteers and supporters!
